# 合成任务对照记录

测试日期：2026-09-23；本次从原始本地结果复核后摘录。原始记录与校验值由个人简历材料库留存；这里只公开不含个人任务、系统路径或会话信息的汇总。

每轮使用相同四项固定合成任务，各组 24 个动作。基线为 Astra 逐步操作，实验组为任务委派；浏览器隔离、主机共享。两轮各组均完成 4/4 任务。安装、开发和父任务汇总成本不在比较内。

| 统计项 | 第一轮：基线 → 委派 | 第二轮：基线 → 委派 |
|---|---:|---:|
| Astra 输入＋输出 token，含缓存输入 | 2,266,693 → 236,295 | 2,256,091 → 192,752 |
| 上项减少比例 | 89.575% | 91.456% |
| Astra 非缓存输入＋输出减少比例 | 75.010% | 91.784% |
| 端到端时间，秒 | 233.712 → 76.511 | 210.581 → 59.630 |
| 任务速率倍数 | 3.055 | 3.532 |
| 委派额外 Jev 输入／输出 token | 2,912 / 300 | 3,040 / 300 |

计算：token 减少比例为 `1 − 委派组 / 基线组`，任务速率比为相同任务量下 `基线耗时 / 委派耗时`。缓存 token、非缓存 token、Jev token 不能按相同价格简单加总为费用；未取得实际账单。

早期另一版三任务测试中，非缓存输入与输出没有改善。这里不把较好的两轮结果说成全部版本的下限，也不将重复同题当成更广的独立任务覆盖。测试集中在低层操作循环，未评价未知应用的长期规划、生产业务正确率和复杂故障恢复。

仓库含合成任务与控制器测试代码，但原主模型宿主会话和完整观测记录不公开；公开材料足以复算上述汇总，不能单凭本表复现当时宿主模型的全部上下文用量。
