## 未覆盖能力的日常出现频率

以下是按任务类型的定性判断，不是本机使用统计，也不代表每个陌生网站都需要接管。

| 需要 Astra/用户的情形 | 日常出现情况 |
|---|---|
| 新文本、未知长程流程、含义不清的目标 | 常见；本来就由 Astra 规划/生成，常规点击填写仍可委派 |
| 富文本/图片剪贴板、多选 select、逐字键盘输入 | 普通表单偶尔；文档编辑、内容创作更常见 |
| iframe 内坐标拖放、Canvas/地图/可视化编辑 | 普通网页较少；设计、白板、地图类应用较常见 |
| JS 原生确认/提示弹窗 | 偶尔，例如离开未保存页面、删除前确认；HTML 对话框多数可走 DOM |
| 下载媒体、裁剪/视觉判断、特殊格式导出 | 按任务出现；普通链接下载、文件上传、DOM 导出已接入 |
| Google Workspace/YouTube 导出 | 已适配未真实验收；相关任务先委派并核验，不能只因未测就接管 |
| 浏览历史、任意开发 CDP/自定义调查 | 日常一般较少，专项排查时常用 |
| 登录、验证码、权限和安全桌面 | 登录/权限变动时出现；需要用户按实际产品要求处理 |

Astra 使用当前官方接口也可能遭遇同一宿主错误。正确升级不等于问题已经解决；完成必须有真实后置证据。没有代表性生产任务样本，不能给出接管百分比。
